# Общий запас призов

Выпуск согласован владельцем 23 ноября 2026. Перед публикацией снимок 10 таблиц и 13 функций восстановлен в отдельной базе; миграция применена с проверкой сохранности участников, прокруток, настроек и вероятностей. Серверные лимиты включены, значения вероятностей оставлены прежними.

## Поведение

- Максимум реальных выигрышей: Noir Blade — 3, Картридж — 20, Бандажка — 50, Soul Ink — 20, Расходники — 30.
- Это общий предел для всех участников, не ежедневный и не индивидуальный. В него входят все уже сохранённые реальные выигрыши данного приза, независимо от текущих дат. Редактирование расписания не пополняет запас.
- Если ранее записано больше нового лимита, история сохраняется и новые выигрыши этого приза прекращаются. Остаток отображается как 0.
- При исчерпании выбранного приза сохраняется обычный результат «Без выигрыша». Попытка расходуется один раз. Вероятность не перераспределяется между другими призами.
- Назначенные тестовые попытки не затрагивают реальный запас. Их результаты исключены из подсчёта.
- Пустое поле лимита означает отсутствие ограничения; 0 отключает реальные выигрыши данного приза. Лимит можно редактировать только через действующую браузерную административную сессию. Для «Без выигрыша» лимита нет.
- Лимиты не обещают раздать весь запас и не распределяют его равномерно по дням.

## Вероятности

Текущие вероятности и даты миграция не меняет. При старых высоких вероятностях запас может закончиться быстро. В админке добавлен черновой план для 9 000 прокруток (1 000 участников × 3 дня × 3 попытки):

| Приз | Шанс, % | Общий лимит |
|---|---:|---:|
| Noir Blade | 0,0333 | 3 |
| Картридж | 0,2222 | 20 |
| Бандажка | 0,5556 | 50 |
| Soul Ink | 0,2222 | 20 |
| Расходники | 0,3333 | 30 |
| Без выигрыша | 98,6334 | — |

Кнопка «Подставить план на 9 000 прокруток» меняет только форму. Применение требует нажатия «Сохранить вероятности и лимиты». Сумма — 100%. Значения вероятностей вводятся с шагом 0,0001%. Поле chance расширяется с numeric(5,2) до numeric(7,4), чтобы хранить эти значения без округления; прежние численные значения сохраняются.

## Серверная защита

Миграция `202611230007_prize_stock.sql` добавляет `roulette_prize_chances.prize_limit`, индекс по реальному призу и триггер перед записью `wjx_spins`. Перед подсчётом получаем блокировку строки соответствующего приза; для ограниченного приза обновляем версию строки. Это сериализует конкурирующие выдачи и вызывает ошибку сериализации вместо использования устаревшего снимка при повышенном уровне изоляции. Проверка, сохранение результата и UUID операции выполняются в одной транзакции. Откат не расходует запас.

`wjx_perform_spin` возвращает фактически сохранённый приз после триггера. Повтор уже записанного UUID возвращает исходный результат даже после изменения лимита. Старый серверный метод `wjx_save_spin` также проходит через триггер. Клиенты anon/authenticated не получают прямых прав на таблицы и SQL-функции.

Лимиты сохраняются вместе с вероятностями одним upsert. Неверный тип, дробное/отрицательное/слишком большое количество и смешанный запрос с пропущенными лимитами отклоняются до записи. Старый клиент, полностью не передающий лимиты, сохраняет только вероятности. Повтор миграции не перезаписывает лимиты, отредактированные после первого применения.

## Проверки и пределы проверки

- Сохранение прежних записей и вероятностей при миграции, повторное применение, права ролей.
- Исчерпание, нулевой и отсутствующий лимит, учёт исторических выигрышей, отсутствие пополнения при смене дат.
- 100 независимых запросов в очереди PGlite: два новых Noir при одном прежнем выигрыше и лимите 3; остальные — без выигрыша. Это локальная проверка логики на одном соединении, не нагрузочный тест Supabase и не проверка нескольких одновременных соединений PostgreSQL.
- Совпадение результата, истории и повторов UUID; откат транзакции; защита старого метода сохранения.
- Изоляция тестовых прокруток, валидация API, вход по паролю, черновой план админки и очистка полей при завершении сессии.
- Полный набор Node-тестов и проверка типов четырёх Edge Functions.
