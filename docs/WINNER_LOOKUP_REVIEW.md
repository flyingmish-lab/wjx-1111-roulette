# Проверка выигрышей и обращение к менеджеру

Подготовлено к согласованной публикации. Игровые данные и настройки не изменяются.

После завершения периода розыгрыша кнопка «Забрать приз» открывает только существующий чат `https://t.me/Wjx_wjxx`. Она доступна при наличии реальных выигрышей, подтверждённых сервером, и выключенном тестовом режиме. Локальная история браузера не определяет наличие выигрыша.

В админ-панели добавлен поиск победителей по нику, имени и Telegram ID. Нажатие на участника открывает все его реальные призы за даты `event_start`–`event_end` из настроек, сгруппированные по названию с количеством и дополнительной разбивкой по дням. Пропуски, пустые результаты и «Без выигрыша» исключены; таблица тестовых прокруток не используется. Поиск по нику выбирает запись по стабильному Telegram ID. Менеджеру следует сверять этот ID с реальным отправителем сообщения: совпадение отображаемого имени или скриншот не подтверждают личность.

Новые SQL-функции доступны только `service_role`. Административные запросы проходят существующую проверку временной браузерной сессии. Статус игрока получает число его призов только по ID из проверенных Telegram initData. Полные отчёты агрегируются в PostgreSQL и не обрезаются лимитом API на число строк.

Проверка: `npm test` — 29 успешных тестов; `npm run check` — все три Edge Function прошли проверку типов. Проверены права SQL-функций, административная авторизация, игнорирование чужого ID в статусе игрока, границы периода, исключение тестовых и пустых исходов, более 1000 записей, безопасный вывод пользовательского текста и переход только в чат менеджера.

Порядок выпуска после подтверждения: миграция `202611190003_event_winner_lookup.sql`, обновление Edge Function `wjx-roulette`, затем `index.html`, `admin.html` и `admin.js` на GitHub Pages. Сначала требуется SQL-функция, поскольку обновлённый API обращается к ней. Секреты и функции авторизации не меняются. Боевой выпуск и проверка после него ещё не выполнены.
