# Дневные лимиты и «Мерч WJX»

Публикация согласована владельцем 23 ноября 2026. Перед выпуском свежий снимок 10 таблиц и 14 функций восстановлен в отдельной базе; 15 реальных и 23 тестовые прокрутки сохранены. Обновлённая wjx-roulette опубликована, миграция 009 применена с транзакционной проверкой сохранности игровых записей, дат, прежних вероятностей и лимитов. Шанс мерча оставлен 0%, лимит — 10 в день.

## Согласованные значения

Лимиты общие для всех участников на каждый календарный день по Москве:

| Приз | Максимум в день |
|---|---:|
| Noir Blade | 3 |
| Картридж | 20 пачек |
| Бандажка | 50 |
| Soul Ink | 20 |
| Расходники | 30 |
| Мерч WJX (комплект) | 10 |

Существующие значения лимитов миграция сохраняет, меняется их смысл: с общего запаса на дневной. Новый приз добавляется с лимитом 10 и вероятностью 0%, чтобы владелец настроил вероятность перед выдачей. Существующие вероятности и расписание не изменяются. Применение нового смысла лимитов увеличивает возможное количество выигрышей за многодневный розыгрыш по сравнению с прежним общим запасом.

## Выдача и статистика

Миграция 009 считает реальные выигрыши по паре `(prize, spin_date)`. Дату новой реальной прокрутки по Москве проверяет существующий серверный RPC в транзакции. Существующая блокировка строки приза и обновление версии строки сохраняются: конкурирующие выдачи одного приза сериализуются, при устаревшем снимке повышенного уровня изоляции операция отклоняется вместо превышения лимита.

После полуночи начинается новая дата и новый дневной остаток; сбрасывать таблицы, запускать планировщик или удалять вчерашние записи не нужно. Изменение даты события не изменяет число выигрышей на фактическую календарную дату. Назначенные тестовые прокрутки остаются отдельными и не расходуют дневной запас. Закончившийся приз заменяется на «Без выигрыша», остальные шансы не перераспределяются.

Админка показывает серверную дату остатков, выиграно сегодня, осталось сегодня и общее число выигрышей. История и проверка победителей остаются за настроенный период события, включая новый приз. Числовое поле `prize_limit` сохраняется, API сообщает `limitScope: day`; сохранение требует этого явного признака, чтобы старая вкладка админки не применила лимиты с прежним пониманием. Старому клиенту предлагается обновить админку.

## Вероятности

Каталог расширен до семи исходов (шесть призов и «Без выигрыша»). Сервер проверяет полный набор имён и сумму 100%. Чтение прежнего каталога из шести исходов временно поддерживается для последовательного выпуска без сбоя прокруток; сохранение новых настроек требует семи исходов.

Кнопка «Рассчитать шансы на день» использует введённые лимиты и `1 000 × число попыток в день` из формы. Она изменяет только черновик вероятностей, сохраняет введённые лимиты и не отправляет запрос. Для пустого безлимитного значения автоматический расчёт отклоняется. Сумма считается в целых единицах 0,0001%, остаток назначается «Без выигрыша».

При трёх попытках в день расчёт для согласованных лимитов:

| Приз | Вероятность, % |
|---|---:|
| Noir Blade | 0,1000 |
| Картридж | 0,6667 |
| Бандажка | 1,6667 |
| Soul Ink | 0,6667 |
| Расходники | 1,0000 |
| Мерч WJX | 0,3333 |
| Без выигрыша | 95,5666 |

Вероятности дают ориентир для 3 000 прокруток в день, не гарантируют раздачу всего запаса или равномерность выдачи в течение дня. После расчёта требуется отдельное сохранение владельцем.

## Изображение

Из пользовательского PNG создан `wjx-merch.webp`: 384 × 370, прозрачность сохранена, качество 88, размер 56 538 байт вместо 2 718 831 байта. Исходный PNG в репозиторий не добавляется. WebP входит в случайные символы барабанов и используется во всех четырёх слотах для подтверждённого выигрыша мерча. Альтернативный текст соответствует названию приза.

## Проверка

- Локальные SQL-тесты: сохранение старых записей/лимитов/вероятностей/расписания, повтор миграции без сброса правок, прошлые/сегодняшние/следующие даты, дневное исчерпание, независимость смены расписания, тестовые попытки, очередь выдач и права ролей.
- Новый реальный приз проходит запись, UUID-повтор, сводку участника и список победителей. Сервер принимает прежний каталог до миграции, отклоняет старый способ сохранения без дневного признака и выбирает мерч при вероятности 100% в изолированном тесте.
- UI-тесты: семь вероятностей/шесть лимитов, черновой расчёт, редактирование лимитов, отсутствие скрытых сохранений, дата остатков, изображение мерча в барабанах и результатах, очистка сессии.
- Восстановлена приватная копия реальной схемы, применены 008/009, проверена сохранность истории, запись мерча и UUID-повтор; сегодняшний остаток уменьшается с 10 до 9 ровно один раз. Всё в локальной памяти, без реальной призовой транзакции.
- Все 82 Node-теста и проверка типов четырёх Edge Functions прошли. Проверки очереди PGlite не являются тестом нескольких соединений PostgreSQL или нагрузочным тестом Supabase.

## Согласованный выпуск после подтверждения

1. Создать свежую приватную копию приложения и проверить её восстановление; не добавлять её в GitHub.
2. Опубликовать новую `wjx-roulette`, которая принимает прежний и новый каталог при прокрутке; старой админке потребуется обновление для сохранения вероятностей.
3. Применить только миграцию 009 с проверкой сохранности игровых записей, прежних вероятностей/лимитов и дат; новая строка мерча — единственное дополнение к каталогу.
4. Опубликовать WebP, страницу игры, версионированный скрипт админки, SQL и тесты. Проверить CI, GitHub Pages и источник live-страницы.
5. Владелец обновляет мини-приложение и админку, выбирает шанс мерча или рассчитывает весь план и сохраняет его. Реальную выдачу проверяет владелец. Агент не создаёт реальные призовые операции и не удаляет тестовые записи.
