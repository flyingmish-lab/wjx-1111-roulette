# Сброс призов отдельного участника

Выпуск подтверждён владельцем 24.11.2026.

В карточке «Прокрутки пользователей» есть отдельная кнопка «Сбросить призы участника». Подтверждение содержит имя и Telegram ID. Действие отменяет все выигрыши выбранного участника за текущие даты розыгрыша, включая отмеченные выданными. Оно не меняет количество попыток, даты, вероятности, лимиты или расход дневного запаса. Возврат физически выданного приза этим действием не оформляется.

Миграция 011 добавляет закрытый RLS журнал запросов и связанный список отменённых призовых spin_id. Исходные реальные прокрутки, результаты UUID, отметки выдачи и тестовые архивы не изменяются и не удаляются. Активные сводки игрока, список победителей и выдача исключают отменённые выигрыши. История администратора показывает пометку «сброшен» и количество отмен. Счётчики расхода запаса по-прежнему учитывают исходные выигрыши.

Проверенная парольная сессия нужна для серверного действия admin_reset_user_prizes. Telegram ID не даёт прав. Запрос содержит отдельный UUID; журнал фиксирует хеш серверной сессии, участника, даты периода, число отмен и UUID существующих выигрышных операций. Общая блокировка участника сериализует прокрутки, сбросы попыток, отмены и выдачу. Повтор одного запроса не отменяет выигрыши, полученные после первоначального сброса. UUID чужого участника отклоняется.

При потере ответа или ошибке обновления списков админка сохраняет UUID запроса в Session Storage и повторяет его. Там нет пароля или токена. Повтор сохранённой прокрутки после отмены возвращает пометку prizeReset вместо старого выигрышного текста. История игрока показывает «Приз сброшен», сводка больше не позволяет забрать этот приз.

Проверки: 94 теста прошли, типы четырёх Edge Functions проверены. Покрыты изоляция участников и дат, исходные записи и выдачи, неизменные попытки/запас, повтор UUID после нового выигрыша, откат, повтор полной SQL-сборки, закрытые роли, отказ Telegram-only, подтверждение пользователя, потеря ответа и восстановление игрока. Миграция также применена к локально восстановленной реальной схеме; все прежние строки и настройки остались без изменений. Реальных сбросов не выполнялось.

После подтверждения публикации: свежая приватная резервная копия через опубликованный экспорт до 011, проверка восстановления; применение только 011; публикация Edge Function и файлов GitHub; проверка CI, Pages и серверных прав. Новый backup-export.sql требует 011 и включает обе таблицы аудита. Сам выпуск никому не сбрасывает призы.

Согласованный серверный выпуск: свежая копия 11 таблиц и 16 функций проверена восстановлением. Миграция 011 применена с транзакционной проверкой сохранности всех прежних записей и настроек; 30 исходных реальных прокруток сохранены, записей сброса и отмен — 0. RLS обеих новых таблиц включена, anon/authenticated не имеют права выполнения сброса. Edge Function обновлена. Публикация не выполняет сброс ни для одного участника.
