# WJX Рулетка

Telegram Mini App с рулеткой и отдельной браузерной админ-панелью.

- `index.html` — игра для всех участников на общих условиях.
- `admin.html`, `admin.js` — настройки, вероятности, статистика, вход по общему паролю и сброс дневных прокруток выбранного пользователя без удаления призов.
- `supabase/functions/` — Telegram API, вход и проверка временных административных сессий.
- `supabase/migrations/` — изменения базы без удаления игровых данных.

Серверная часть включает проверку общего пароля, временные сессии и ручной сброс дневных попыток с сохранением выигрышей. Административных прав по Telegram ID нет. Подробности защиты, результаты проверки и порядок согласованного выпуска: [docs/ADMIN_AUTH_REVIEW.md](docs/ADMIN_AUTH_REVIEW.md).

Проверка реальных выигрышей участника и переход к менеджеру после окончания розыгрыша: [docs/WINNER_LOOKUP_REVIEW.md](docs/WINNER_LOOKUP_REVIEW.md).

Подготовленные исправления сетевых сбоев, восстановление истории и учёт выдачи: [docs/RELIABILITY_RELEASE_REVIEW.md](docs/RELIABILITY_RELEASE_REVIEW.md).

Команды личного чата Telegram-бота и защищённое подключение обработчика: [docs/TELEGRAM_BOT_COMMANDS_REVIEW.md](docs/TELEGRAM_BOT_COMMANDS_REVIEW.md).

## Проверка разработки

Требуется Node.js 24. Зависимости предназначены для разработки, на GitHub Pages сборка не нужна.

```sh
npm ci
npm test
npm run check
```

Тесты используют искусственный пароль и искусственные ключи. Боевые секреты не должны попадать в файлы, коммиты и логи.

Текущий режим использует только реальные прокрутки; старые тестовые записи сохраняются в архиве. Порядок согласованного выпуска сброса: [docs/REAL_SPINS_RESET_REVIEW.md](docs/REAL_SPINS_RESET_REVIEW.md).
