# WJX 11.11

Telegram Mini App с рулеткой и отдельной браузерной админ-панелью.

- `index.html` — игра для всех участников на общих условиях.
- `admin.html`, `admin.js` — настройки, вероятности, статистика, вход по общему паролю и назначение тестовых попыток пользователям.
- `supabase/functions/` — Telegram API, вход и проверка временных административных сессий.
- `supabase/migrations/` — изменения базы без удаления игровых данных.

Серверная часть включает проверку общего пароля, временные сессии и отдельные тестовые попытки. Административных прав по Telegram ID нет. Подробности защиты, результаты проверки и порядок согласованного выпуска: [docs/ADMIN_AUTH_REVIEW.md](docs/ADMIN_AUTH_REVIEW.md).

Проверка реальных выигрышей участника и переход к менеджеру после окончания розыгрыша: [docs/WINNER_LOOKUP_REVIEW.md](docs/WINNER_LOOKUP_REVIEW.md).

## Проверка разработки

Требуется Node.js 24. Зависимости предназначены для разработки, на GitHub Pages сборка не нужна.

```sh
npm ci
npm test
npm run check
```

Тесты используют искусственный пароль и искусственные ключи. Боевые секреты не должны попадать в файлы, коммиты и логи.
