🎯 Вероятности и количество призов

Лимит общий для всех участников на один день по Москве. В полночь начинается новый дневной запас. Сегодняшние реальные выигрыши учитываются; смена дат розыгрыша запас не обнуляет. Тестовые попытки запас не расходуют.

Пустое количество — без ограничения, 0 — приз недоступен. Когда дневной запас закончится, выпадение этого приза станет «Без выигрыша». Лимит не гарантирует, что все призы будут выиграны.

Расчёт по введённым дневным лимитам: 1 000 участников × количество попыток в день из формы. Значения начнут действовать после сохранения.
